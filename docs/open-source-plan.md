# Open-Source Plan

Last updated: 2026-08-27

## Current Status

This repository does not currently contain a root `LICENSE` file. Until the repository owner adds an explicit license, the project should not be described as legally open source in the SCF application or public documentation.

The Soroban contract source is public in this repository and is intended to remain publicly auditable.

## Required Owner Decision Before Submission

The repository owner should choose and add a license before presenting the repository as open source. Recommended permissive options:

- MIT License
- Apache License 2.0

After choosing the license:

1. Add a root `LICENSE` file with the selected license text.
2. Ensure package metadata matches the selected license.
3. Update the root README and SCF materials to say the repository is open source under that license.
4. Confirm generated bindings and contract code are covered by the same license or clearly document any exception.

## Submission Language Until Then

Use this wording:

> The Yolixa Soroban contract source is publicly auditable in the repository. A final open-source license decision remains before the repository is presented as legally open source.

Do not use this wording yet:

> Yolixa is open source.
