# Known Limitations

Current limitations are intentional pre-SCF MVP boundaries:

- Stellar Testnet only.
- Native XLM only.
- Freighter is the default supported wallet.
- Rabet code exists for future compatibility, but Freighter is the only wallet confidently advertised for the current MVP unless Rabet is separately browser-validated and explicitly enabled.
- No USDC payments.
- No custom Stellar asset payments.
- No trustline creation or management UX.
- No YLX on-chain reward distribution.
- No YLX claim system.
- No token minting.
- No staking, liquidity pools, DeFi, or cross-chain integration.
- No production Mainnet launch.
- No advanced creator analytics.
- No advanced admin monitoring or moderation platform.
- No mobile app.
- Soroban contract/router code exists in the repository as future/experimental work, but it is not the current default MVP payment path.

Manual evidence still needed before SCF submission:

- deployed demo URL,
- demo video,
- real Testnet transaction hash,
- founder/team details,
- final budget and milestone commitments.
